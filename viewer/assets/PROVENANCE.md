# Offline Natural Earth background

`natural_earth_110m_countries.geojson` is a geometry-only, compact GeoJSON
extraction from the Natural Earth low-resolution countries fixture distributed
with pyogrio. It contains 177 country/territory features and is used only
for a lightweight global background in the HTML viewer.

Source fixture: `pyogrio/tests/fixtures/naturalearth_lowres/naturalearth_lowres.shp`
(same public-domain Natural Earth 1:110 million approximate level). No scientific GWEH polygon
or numerical indicator is generated from this background.
