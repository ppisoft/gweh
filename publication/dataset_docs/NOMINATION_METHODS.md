# Candidate nomination

GWEH evaluates a fixed set of expert-nominated wind-energy systems. The
`metadata/candidate_nomination_register.csv` table gives each candidate ID and
its scientific nomination basis. Nomination is not a resource score, does not
determine region boundaries, and is not a claim of exhaustive global coverage.

Selection and geometry are calculated by the accompanying GWEH software.
Institutional evidence and final Strategic-S assessments are documented under
`metadata/strategic_s/`. The source register in `metadata/source_register.csv`
identifies upstream construction and validation datasets. Candidate nomination
and independent omission review are described in the scientific manuscript.
